# yove lou

Two-deck CDJ-style player in Flutter (landscape phone). See [FEATURES.md](FEATURES.md).

## First run
```
flutter create . --project-name yove_lou --org com.yovelou --platforms=android
flutter pub get
flutter run
```
`flutter create .` only adds the missing platform folders (android/ etc.); it keeps `lib/` and `pubspec.yaml`.
If it generates `test/widget_test.dart` (references a counter app), delete it.
